    📋 Politique de confidentialité

    Données personnelles
    Bari Codex ne collecte, ne transmet et ne stocke aucune donnée sur un serveur. Toutes vos données (profil, poids, recettes, planner) sont stockées uniquement dans le navigateur de votre appareil (localStorage). Elles ne quittent jamais votre appareil.

    Clé API Groq
    Si vous entrez une clé API Groq pour activer Mochi, cette clé est stockée localement et utilisée uniquement pour envoyer vos questions à l'API Groq. Groq est un service tiers — consultez leur politique de confidentialité sur groq.com.

    Avertissement médical
    Bari Codex est un outil d'organisation et de suivi. Il ne remplace pas un suivi médical professionnel. Pour toute décision médicale concernant votre chirurgie bariatrique, consultez toujours votre chirurgien, votre médecin ou votre diététicien spécialisé.
